# DesiMart Jharkhand — Step 2 Backend Foundation

Owner: Akshay Kumar Sahu

## What is included
- Express API
- Customer/user creation
- Seller registration
- Product listing/creation
- Cart endpoint
- Order creation
- Admin summary
- Health check

## Important
This step uses in-memory data only. Restarting the server clears data.
It is NOT production-ready yet.

## Run on a computer
1. Install Node.js LTS.
2. Open this folder in Terminal.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000/api/health
